# 05 · AI evaluation platform

Automated tests for the other projects, using the real project code, scored per model and shown side by side.

**Stack:** [promptfoo](https://promptfoo.dev) · custom Python providers · Ollama `gemma3:12b` as the local judge for `llm-rubric`

## What it tests

| Suite | Tests | Checks |
|---|---|---|
| `rag.yaml` | 10 questions × 2 models (`gemma3:12b`, `qwen3:8b`) | exact facts, "Not in the documents" for questions it can't answer, conflicting sources, a question in Swedish, and every answer cites a source |
| `invoices.yaml` | 5 invoices | exact totals, VAT rates, dates, line counts, and that the wrong invoice is flagged |

The test data is made up: `fixtures/handbook/` is an employee handbook for a fictional studio, plus an old IT FAQ that contradicts it on purpose. Invoices are generated by `03-invoices/make_samples.py`.

`providers.py` runs the actual project code (retrieval + answer, or extraction + checks), not just a bare model, so a change to chunking or prompts shows up in the scores. The RAG suite uses its own database (`.eval-db`).

## Run

```powershell
npm install -g promptfoo
cd 05-eval
promptfoo eval -c rag.yaml -j 1
promptfoo eval -c invoices.yaml -j 1
promptfoo view
```

`-j 1` runs one test at a time; with 12 GB of VRAM, parallel tests make Ollama swap models.

## Results

| Run | RAG | Invoices |
|---|---|---|
| First run | 16/20 (80 %) | 5/5 |
| After fixing what it found | 20/20 (100 %) | 5/5 |

What the first run caught in `01-rag`, and the fix:

1. **A question in Swedish got "Not in the documents" from both models.** `nomic-embed-text` is English-only. Fix: non-English questions are also searched as an English translation.
2. **Conflicting sources were listed side by side** (4 000 vs 6 000 SEK) without saying which applies. Fix: each chunk now carries its document's title ("IT FAQ (old, 2024)"), and the prompt says to prefer the newer document.
3. **An incomplete answer** about remote work left out the "three days a week" rule. Fix: the prompt asks for the complete answer, including conditions and limits.
